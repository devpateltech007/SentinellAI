# Example Labs Access Control Policy

Version 1.4. Owner: Security team. Applies to every employee and contractor.
This is a made-up policy written to test ComplianceLens.

## 1. Scope

This policy covers access to Example Labs systems, including the AWS account and the
GitHub organization.

## 2. Multi-factor authentication

Every user who can sign in to the AWS console must use multi-factor authentication
(MFA). This applies to employees, contractors and administrators alike.

GitHub accounts in the Example Labs organization must have two-factor authentication
turned on.

## 3. Least privilege

People get only the access their job needs. Administrator access is approved by the
Security team and reviewed every quarter.

## 4. Shared accounts

Shared logins are not allowed. Every person signs in with their own account.
